Accessibility statement

This statement covers the website at sightpress.org. It doesn’t cover the documentation site or SightPress itself, which have their own checks.

Our aim

We want everyone to be able to use this website, including people who use a screen reader, a magnifier, a braille display, voice control, switch access or a keyboard alone. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at level AA.

You should be able to:

  • move around every page with a keyboard alone, and always see where you are;
  • zoom in to 400% with the text reflowing into a single column;
  • choose a light or dark colour scheme, or use your system’s high-contrast colours;
  • use every page without JavaScript;
  • follow our blog in a feed reader, or read its articles as Markdown.

The site has no cookies, trackers, third-party scripts or third-party fonts. The sharing links are plain links: nothing loads from a social network until you choose one.

How accessible this website is

We believe this website meets WCAG 2.2 AA. If you find something that doesn’t, please tell us: we treat accessibility barriers as bugs.

How we test it

  • Every change is checked automatically for WCAG 2.2 AA problems with axe-core, in light and dark mode and on a narrow screen, and the HTML of every page is validated.
  • We test the navigation and the colour scheme button with a keyboard alone.
  • Before a new kind of page goes live, we read it with NVDA and Firefox on Windows and VoiceOver and Safari on macOS.

Tell us about a barrier

If something on this website is hard to use, email team@sightpress.org. Tell us the page, what you were trying to do and, if you use one, your assistive technology. A real person reads every message and replies within 5 working days.

If you’d like this website’s content in another format, write to the same address.
