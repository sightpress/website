Frequently asked questions

Short answers to the questions people ask us most. If yours isn’t here, email team@sightpress.org: a real person reads every message.

  • What is SightPress?

    SightPress is an accessible, open-source content management system (CMS) for building and running many websites in many languages from one installation. It is designed with blind and low-vision content creators, and audiences who use assistive technology, in mind.

  • Is SightPress only for blind people?

    No. SightPress is for everyone: charities, small businesses, public bodies and individuals. It is built so that blind and low-vision people can use every part of it, and that makes it clearer and calmer for everybody else too.

  • Can I use SightPress with a screen reader?

    Yes, that is what it is built for. The admin, sign-in pages, default theme and emails target WCAG 2.2 AA, and SightPress as an authoring tool targets ATAG 2.0 AA. Tasks work with a keyboard alone and with a screen reader, nothing depends on dragging, colour or a CAPTCHA, and there is a command-line tool for administration tasks too.

  • Will SightPress help me publish accessible content?

    Yes. Images need a description, or an explicit choice to mark them as decorative, and videos and recordings need captions and a transcript. SightPress checks each page before it goes live, including its link text and heading order, explains anything to fix, and won’t publish a page with an accessibility error.

  • Is SightPress free and open source?

    Yes. SightPress is licensed GPL-3.0-or-later, so anyone can use it, inspect it and improve it. The code is developed in the open on GitHub.

  • What do I need to run SightPress?

    SightPress is written in modern, object-oriented PHP and ships with ready-made Docker files. It is tested on MariaDB, MySQL, PostgreSQL and SQLite, runs on FrankenPHP, nginx or Apache, and stores files on your own server or, if you choose, in cloud storage. It loads no third-party scripts or fonts.

  • Will my site be easy to find in search engines and AI answers?

    SightPress is built for it from the start: server-rendered pages, a title, description and structured data for every page, per-language addresses, a sitemap for each language, and a Markdown version of every public page for AI tools. Each site decides how AI crawlers may use its content. It uses no tricks: it makes your site clear and eligible, and leaves the content to you.

  • Does SightPress use AI?

    Only if you want it to. The AI assistant is off for new sites. An admin can turn it on with the organisation’s own key from Anthropic, OpenAI or Mistral, or connect a compatible or self-hosted service. Nothing it writes is used until a person accepts it, and it never publishes anything.

  • When can I try SightPress?

    Now, if you are a developer or a tester: test release 0.4.0 runs on your own computer, and the getting started guide explains how. Test releases aren’t ready for live websites yet; version 1.0 will be. Email team@sightpress.org to hear when it is ready.
