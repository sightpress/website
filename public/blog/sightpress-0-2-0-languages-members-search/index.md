# SightPress 0.2.0: languages, members and site search

By Pedro Ferreira

19 November 2026

SightPress 0.2.0 is out. The first release let you publish a website. This one helps you run it over time, in more than one language and for more than one kind of audience.

## What's new

### Publish in several languages

A site can now use any available language, and each page can have its own translation with its own title, address and content. Translations start as drafts, so nothing goes live by accident. Search engines are told which pages are translations of each other, and each language gets its own sitemap.

The admin panel, site texts and emails are now available in European Portuguese and Spanish as well as UK English.

### Search every site

Every page now has a search form, with no outside service to pay for or configure. It ignores capitals and accents, so "cafe" finds "Café". Results show short extracts with your words marked in bold and underlined, so the match doesn't depend on colour.

### Open a site to members

People can create their own account when a site allows it, confirming it with a six-digit code from an email. You can make single pages or a whole site readable only by signed-in members, and those pages stay out of search engines.

### Change pages with confidence

- **Older versions:** compare any version word by word. Changes are written out as "removed" and "added", so they read the same with a screen reader and without colour.
- **Safe restores:** bringing back an older version never publishes it.
- **Scheduling:** publish or unpublish a page at a set time.
- **Moving pages:** copy, archive, trash and move pages, with redirects that keep old addresses working.

### Choose your features

Admins can turn optional features on or off for each site. Turning one off keeps its data, so turning it back on brings everything back as it was.

## What it isn't yet

SightPress is still an early release for trying out and testing, and running it on a public server isn't covered yet.
